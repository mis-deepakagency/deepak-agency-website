# Brand logos

Brand ka logo isi folder mein upload karein (PNG / JPG / SVG / WEBP).

1. GitHub par is folder mein jaayein: logos/brands
2. **Add file → Upload files** dabayein, logo ki file drag karein, **Commit changes** dabayein.
3. Google Sheet "Deepak Agency Website Data" → **Brands** tab mein brand ke saamne **Logo** column mein file ka naam likhein, jaise `macho.png`.

Tips: file naam chhota rakhein, space na ho (macho.png, dixcy-scott.png). Transparent PNG sabse achha dikhta hai.
