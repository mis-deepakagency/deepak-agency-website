# Department photos

Har department ki ek photo yahan upload karein (JPG / PNG / WEBP), jaise `tshirt.jpg`.
Phir Google Sheet → **Departments** tab → **Photo** column mein file ka naam likhein.
Photo na ho to website par department ka chitra (illustration) dikhega.
Achhi photo: rack ya table par kapde saaf dikhein, roshni achhi ho, landscape (aadi) photo.
